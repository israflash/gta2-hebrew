# GTA 2 בעברית — v1.0.10

## מה השתנה

- תיקוני תרגום ותצוגת GXT/brief קודמים נכללו בבניית release מעודכנת.
- בדיקות ה־QA המקומיות יכולות להעביר סכומים דינמיים למסלול ה־HUD המקורי, כולל `bdone`.
- כותרת המשימה נשארת מוסתרת עד שחישוב מיקום המשחק תקין, למניעת הבזק בפינת המסך.
- תווית הדובר של GXT 1197 עודכנה לריפרייד נודל, עם דיוקן Yakuza הקבוצתי המקורי.

## אימות מקומי

- שבע בדיקות רגרסיה של Node ובניית Pages סטטית עברו.
- רצף brief, כותרות, תפריט, מפה/מינימפה, fallback באנגלית, ייבוא/ייצוא/טעינת snapshot ומשימת Downtown אחת נבדקו בדפדפן מבודד.
- לא נכללו באתר קובצי משחק או שמירות. קובצי המשחק נשארים מקומיים.

## מגבלות בדיקה

לא בוצעה משימה טבעית ב־Residential וב־Industrial; שמע לא אומת בהאזנה, ומולטיפלייר בין שני דפדפנים ותאימות שמירה היסטורית לא אומתו בסבב זה.
