# GTA 2 בעברית — v1.0.11

## תיקוני תפריט

- יישור של שלוש תוויות התפריט הראשי בעברית לקצה ימני משותף, תוך שמירה על מיקום וריווח לפי מסך המקור ועל צבע הבחירה.
- חלון השליטה שנפתח מתוך „אפשרויות” מקבל כעת כיווניות לפי השפה. בעברית תיאור הפעולה מיושר לימין, ומקשי המקלדת מוצגים משמאל ובכיווניות LTR.
- חישוב רוחב תוויות התפריט נשמר במטמון ומבוצע מחדש רק כשהתפריט, הגופן או גודל התצוגה משתנים.

## אימות

- נבנה מנוע release ונארז אתר Pages סטטי.
- שבע בדיקות Node, בדיקות תחביר JavaScript ו-`git diff --check` עברו.
- Chrome מבודד ב-1200×800 בדק תפריט עברי, יישור משותף, צבע בחירה, פתיחת Options, כיווניות חלון השליטה וסגירה ב-Escape.
- לא שונו WASM, משחקיות או מערכת שמירות. בדיקת משחק רחבה לא הורצה בסבב זה.
